# گزارش آنلاین وضعیت ریخته‌گری

این پروژه یک داشبورد رسمی و راست‌به‌چپ برای تحلیل فایل «مسترلیست گزارش کیفی» است. فایل `index.html` داشبورد اصلی و `data.json` دادهٔ آمادهٔ تولیدشده از فایل اکسل است. فایل مستقل `excel-to-json.html` برای آماده‌سازی داده ارائه می‌شود، اما از صفحه اصلی لینک نشده است.

## استفاده در GitHub Pages یا هر سرور استاتیک

تمام فایل‌های این پوشه را در ریشهٔ مخزن قرار دهید و فایل `index.html` را به‌عنوان صفحهٔ اصلی منتشر کنید. برای انتشار دادهٔ جدید، فایل آمادهٔ `data.json` را کنار `index.html` جایگزین نمایید. ابزار مستقل تبدیل اکسل را فقط در صورت نیاز جداگانه باز کنید.

## تنظیم لوگوها

لوگوها را در مسیرهای زیر داخل مخزن GitHub قرار دهید تا داشبورد آن‌ها را به‌صورت خودکار از همان مخزن بخواند:

```text
assets/pouyanovin.png
assets/ezam.png
assets/BNazanin.woff2  # اختیاری؛ برای تضمین فونت فارسی در همه مرورگرها
```

مقدار `pouyanovin` برای جایگاه سمت راست و مقدار `ezam` برای جایگاه سمت چپ استفاده می‌شود. مسیرها در انتهای `index.html` در شیء `window.DASHBOARD_LOGOS` تنظیم شده‌اند؛ در صورت استفاده از نام یا مسیر دیگر، همان شیء را ویرایش کنید.

## اجرای محلی

با Node.js اجرا کنید:

```bash
npm start
```

سپس آدرس `http://localhost:3000` را باز کنید. نمودارها با Plotly از CDN خوانده می‌شوند.
